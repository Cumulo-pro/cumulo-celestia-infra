Live status of the Fibre data availability network on Celestia `mocha-5`, built only from badges that read Cumulo's public Fibre Network Monitor API (`https://fibre-api.cumulo.com.es`). No backend, no JavaScript, no tokens: copy any badge into your own README. See the [usage guide](./fibre-api-guide.md) for endpoints and conventions.

> [!NOTE]
> Badges are cached by shields.io (10 minutes) and by GitHub, so this page is a status board delayed by several minutes, not a real time feed. `null` in the API means no data, never zero; shields.io then shows `no result`.

## 9. What needs Prometheus

Badges show the current value only. History, thresholds and alerts need the Prometheus metrics of the API. See the [usage guide](./fibre-api-guide.md).

| Metric | Use |
|---|---|
| `fibre_ready_meets_threshold` | Ready stake meets 2/3, for alerting |
| `fibre_validators_needed_to_threshold` | Validators still needed for 2/3 |
| `fibre_quorum_rtt_seconds{region}` | Quorum round trip per probe region, over time |
| `fibre_liveness_coefficient{dimension}` | Liveness coefficient history |
| `fibre_network_online_ratio_24h` | Network online ratio, as a time series |

## 10. Build your own

Every badge is a [shields.io dynamic JSON badge](https://shields.io/badges/dynamic-json-badge):

```
https://img.shields.io/badge/dynamic/json?url=<API URL>&query=<JSONPath>&label=<text>&suffix=<text>&color=<color>&style=flat&cacheSeconds=600
```

All parameters are fully URL encoded (`$` is `%24`, `[` is `%5B`, `?` is `%3F`, `=` is `%3D`, `&` is `%26`).

**Add a metric**

1. Find the field with `jq`: `curl -s https://fibre-api.cumulo.com.es/v1/mocha-5/summary | jq '.readiness.ready_stake_pct'`
2. Convert the jq path to JSONPath: `.readiness.ready_stake_pct` becomes `$.readiness.ready_stake_pct`, and `.quorum_by_region[0].reached` stays `$.quorum_by_region[0].reached`. Prefer array indexes over filters like `[?(@.region=='US')]`.
3. Build the URL with `urllib.parse.urlencode(params, safe="", quote_via=quote)`.


**Troubleshooting**

| Badge shows | Meaning | Fix |
|---|---|---|
| `invalid query` | The JSONPath is malformed | Check brackets and that it starts with `$` |
| `no result` | The path does not exist (yet), or the list is empty | Check the field with `jq`, then regenerate the page |
| `inaccessible` | shields.io could not reach or parse the API | Open the API URL in a browser; check it returns JSON |
| `429` or `inaccessible` in bursts | Rate limit (120 requests per minute per IP) | Keep `cacheSeconds=600`; avoid more badges per endpoint |
| Old value | GitHub and shields.io cache images | Wait a few minutes or reload without cache |
| Large raw numbers | Badges cannot do arithmetic | Read the suffix: amounts in utia, sizes in bytes, durations in ms |
